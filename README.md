# linkedin-bots

Python + Selenium bots that automate LinkedIn outreach by driving your own
already-logged-in Chrome session.

## Installation

```bash
python -m venv .venv
.venv/Scripts/python -m pip install -e ".[dev]"   # .venv/bin/python on Linux/macOS
```

## Running the tests

```bash
python -m pytest
```
